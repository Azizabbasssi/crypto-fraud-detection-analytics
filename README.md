## 🔬 Core Investigative Workflows

### 1. Ledger Ingestion & Transaction Tracing
*   Analyzed raw public blockchain ledgers to parse inbound/outbound transaction hashes, isolating obfuscated volume jumps and structured high-frequency splits.
*   Traced token tracking arrays to construct chronological flow timelines across multiple intermediate wallets.

### 2. Wallet Clustering & Identity Attribution
*   Utilized public blockchain intelligence methodologies to cluster address nodes interacting with shared mixers or common smart contracts.
*   Cross-referenced transaction headers with known decentralized exchange (DEX) operational liquidity pools to locate potential endpoint asset off-ramps.

### 3. Smart Contract & Exploit Auditing
*   Evaluated transaction data payloads to uncover structural anomalies, logic flaws, or unauthorized re-entrancy signatures used in malicious network drainage.
*   Documented multi-signature wallet changes and governance override patterns used to secure or redirect illicit holdings.
